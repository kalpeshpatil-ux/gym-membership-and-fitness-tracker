🎓 Academic OOP Concepts Implementation Matrix

        

          This project was structured specifically to showcase the Five Core Pillars of Object-Oriented Programming (OOP) as required for academic evaluation:
        


        

          
          

            
1. Abstraction (Pure Virtual Classes)

            

              Hiding complex implementation details behind clean, mandatory interfaces.
            

            
              class Person { virtual void displayInfo() = 0; };

              class MembershipPlan { virtual double getMonthlyFee() = 0; };
            
          


          

            
2. Encapsulation (Data Shielding)

            

              Restricting direct variable manipulation via private specifiers and safe setters/getters.
            

            
              private: vector<Workout> workouts; double totalFeesPaid;

              public: void updateWeight(double w); double calculateBMI();
            
          


          

            
3. Inheritance ("Is-A" Hierarchy)

            

              Reusing common persona attributes and specialized membership subscription rules.
            

            
              class Member : public Person { ... };

              class BasicPlan : public MembershipPlan { ... };
            
          


          

            
4. Polymorphism (Dynamic Dispatch)

            

              Dynamic binding via virtual tables (`vtable`) allowing uniform invocation of derived actions.
            

            
              for(auto &m : members) m->displayInfo(); // Dynamic

              virtual ~Person() {} // Safe polymorphic cleanup
            
          


          

            
5. Composition ("Has-A" Relationship)

            

              Building complex structures by embedding specialized sub-objects with controlled lifecycles.
            

            
              class Member { FitnessTracker tracker; };

              class FitnessTracker { vector<Workout> workouts; };
